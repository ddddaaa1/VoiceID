# ASVspoof 2021 LA Reference Reproduction v1

## Purpose

This experiment validates VoiceID's dependency-free EER and normalized t-DCF implementation
against the official ASVspoof 2021 Logical Access evaluation protocol. It evaluates the four score
files distributed by the challenge organizers; it does **not** evaluate VoiceID's AASIST adapter.

The downloaded protocol and score files are not committed. Every report records both input hashes,
the exact coefficients, trial counts, score direction, and an explicit interpretation warning.

## Reproduced pooled results

| Official baseline score file | CM EER | Minimum normalized t-DCF |
|---|---:|---:|
| CQCC-GMM | 15.6181% | 0.497418 |
| LFCC-GMM | 19.2967% | 0.575787 |
| LFCC-LCNN | 9.2601% | 0.344510 |
| RawNet2 | 9.5019% | 0.425745 |

The VoiceID implementation was also compared in-process to the official `eval_metrics.py` sweep on
all 148,176 pooled evaluation trials. EER, minimum normalized t-DCF, and the selected thresholds
matched to floating-point precision.

## Reproduce

Download and extract the official key package using the links in the
[ASVspoof evaluation package](https://github.com/asvspoof-challenge/2021/tree/main/eval-package).
Then run, for example:

```bash
uv run python scripts/evaluate_asvspoof2021.py \
  keys/LA/CM/trial_metadata.txt \
  keys/LA/CM/RawNet2/score.txt \
  --subset eval \
  --c0 0.07889105248001665 \
  --c1 0.8616089475199833 \
  --c2 0.3482101348210135 \
  --system-id asvspoof2021-official-RawNet2-baseline \
  --output /tmp/rawnet2.json
```

The strict join fails on malformed metadata, duplicate IDs, missing selected trials, non-finite
scores, oversized inputs, or unsupported subsets.

## Limitations and next evidence

- These are organizer-supplied baseline scores, not scores generated by VoiceID.
- Minimum t-DCF is an oracle sweep on evaluation and is not an application threshold.
- Results cover ASVspoof 2021 LA conditions and cannot establish replay, microphone, demographic,
  language, or current-generator performance.
- End-to-end AASIST evidence requires the separately distributed ASVspoof audio corpus. The 2019
  LA archive is 7.12 GB and governed by its included license; it must not be silently downloaded or
  redistributed as part of a source checkout.
- Anti-spoofing therefore remains disabled in the default API.
